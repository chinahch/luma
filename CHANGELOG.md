# Changelog

## 0.1.0-preview (2026-11-12)
- Initial portable Go/Vue panel, PostgreSQL schema, user/admin sessions and Node/Machine management.
- Legacy REST adapter, reliable batch receiver, raw/billed usage query, CSV export and basic VLESS subscriptions.
- Compose source builds, private configuration example, backup and empty-database restore procedures.
- Production deployment, real proxy-node E2E, low-memory ARM64 runtime, payment/tickets, automatic billing periods, full protocol subscriptions and XLSX remain outside this preview's validated capability.
