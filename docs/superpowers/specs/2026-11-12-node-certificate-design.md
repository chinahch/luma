# 节点证书配置与自动下发设计

## 用户要求与现状

将需要普通 TLS 证书的节点改成用户提供的 XB 截图中的表单：证书模式、证书域名、通知邮箱、DNS 提供商、逐行 KEY=VALUE 凭据，保存节点后自动下发。保留 Go/Vue 面板和原生 caddy 节点，不要求节点安装 Docker，也不让用户通过 SSH 手工准备证书。

现有 ProtocolPreset 只生成 cert_mode=file；节点编辑只有完整 JSON。已有加密 node_private 保存和仅归属机器可读取配置的接口。已发布节点基于 Xboard-Node 固定提交 0a29338e1f102a462363ce3527417029f89bab28，具备 CertMagic/libdns DNS-01、HTTP-01、文件、PEM 内容以及续期后更新内核的基础能力。这些能力必须通过本次端到端测试核实，不能仅凭字段存在宣称可用。

## 方式与取舍

采用面板下发 cert_config、归属节点负责申请和续期。沿用现有机器身份及配置同步，不增加人工复制永久令牌步骤。集中在面板申请并分发私钥增加跨机私钥同步和续期扇出，本次不采用。用户已指定截图交互及自动下发；节点端执行是符合现有架构的实现选择。

## 表单行为

- 新建 Hysteria2、AnyTLS TLS、VMess WS TLS、VLESS WS TLS、VLESS XHTTP TLS H3 等需要证书的预设默认 DNS-01（ACME）。REALITY 不要求普通证书，CF Tunnel 继续由其外部 TLS 终结方式处理。
- 证书区域独立于“生成协议预设”按钮，在编辑已有节点时也能读取并修改，不因修改证书重生成 REALITY、ENC、SS 或用户密钥。
- DNS 模式提供证书域名、通知邮箱、可搜索 DNS 提供商选择及 KEY=VALUE 多行输入，显示对应提供商的凭据名称说明。Cloudflare 支持截图中的 CF_API_TOKEN 别名。支持范围严格对齐固定原生构建实际包含的提供商，不宣称任意 acme.sh 提供商均可用。
- 兼容已有“本机文件路径”；另外开放节点已有的 HTTP-01 和粘贴 PEM 证书/私钥模式。切换模式只提交所选模式需要的字段，不把旧 DNS 凭据带到别的提供商/模式。不新增自动自签名降级。
- 新建时证书域名默认取具体 TLS 服务器名称，仍可单独修改。订阅对外主机、TLS SNI 和证书域名是不同字段；公网 IP 不可替代 DNS-01 域名。DNS-01 支持泛域名时必须覆盖节点的具体 SNI，订阅不能输出 *.example.com 作为 SNI；HTTP-01 不接受泛域名。
- 已有文件证书保持原模式，不自动转 DNS，不清空现有配置；打开后取消不产生下发或 ACME 申请。保存节点统一提交协议、证书、落地、路由和套餐配置，失败不留下半份更新。

## 凭据与校验

- 复用 LUMA_MASTER_KEY 加密保存完整私密配置；普通节点列表、用户订阅、探测结果和普通日志不包含 DNS 密钥或 PEM 私钥。节点机仅能获取其归属且启用节点的配置。
- DNS 凭据是数据而非 shell：逐行按第一个等号分割；拒绝无效变量名、重复键、空必填值、超量/超长输入；不执行 export、命令替换或任意 shell，不写入进程全局环境。值中的后续等号必须保留。
- DNS 凭据输入默认遮蔽，编辑显示“已保存”，未填写时保留旧凭据；更换提供商或明确替换时要求完整的新凭据，不将不同提供商旧密钥隐式合并。既有高级 JSON 入口属于管理员权限，界面不额外将密钥复制到预览或成功提示中。
- 服务端对预设生成与直接 JSON 节点保存均校验：模式、合法域名/SNI 覆盖、邮箱、提供商、必填/可接受凭据键、路径或 PEM 配对。非法输入在保存前拒绝，不向节点发送明显无效的证书配置。
- HTTP-01 明示 DNS 必须指向节点且公网 TCP 80 可达；DNS-01 不要求开放 80。DNS 凭据权限错误、DNS 传播、ACME 限流/网络错误必须按真实失败报告，不能显示为已签发，也不能自动改用自签名证书。

## 自动下发与生命周期

- 保存后沿用当前受认证的机器发现/配置拉取链路自动同步，不把轮询描述成即时 WebSocket 推送。保存成功提示“已保存，等待服务器同步并申请证书”，与已签发明确区分。
- 首次申请成功后才启用普通 TLS 监听；失败需在现有故障查询中得到证书阶段提示。可在现有故障查询增加固定、脱敏的证书状态，不上传 DNS API 原始错误响应和私钥。
- 同机多个逻辑节点的证书存储相互隔离；重启、重复拉取相同配置应复用有效缓存，避免重复下单。校验续期成功更新对应运行中内核；修改配置或删除节点应停止旧证书管理任务。
- 在实现阶段核实当前原生版本的缓存/重试/停止行为。如果必须修复节点端，修复纳入同一功能并发布新预览版、同步面板安装来源；否则复用已发布 v0.1.3-preview。不能以面板表单通过代替原生行为验证。

## 验证与交付

1. 前后端验证不同模式、KEY=VALUE 解析、旧配置回填/保留、仅变更证书不重生成协议密钥；构建检查通过。
2. 真实 PostgreSQL 验证保存后加密、普通接口脱敏、机器归属隔离、完整 cert_config 自动送达归属节点及非法保存事务回滚。
3. 原生测试使用本地可控 ACME/DNS 或等价可注入组件，覆盖初次签发、失败、相同配置重复同步/重启缓存、多节点隔离、续期更新和停止；不使用用户截图中的域名/密钥，不对公共 CA 发测试订单。实际公网生产签发仍依赖用户有效 DNS 凭据与服务器网络。
4. 浏览器核对新建与编辑证书表单、模式切换及错误信息。发布双仓所需变更，给出 /opt/luma 更新命令；如节点端有改动，说明原服务器记录上原位更新节点的步骤。

## 范围

本次不新增集中证书仓库、跨机器私钥共享、DNS 托管、任意脚本执行、任意 CA URL 输入、面板自身 HTTPS 部署或支付等其他功能。截图中的其他选项卡已有落地/路由功能继续沿用。

## 待确认

按以上默认 DNS-01、节点端申请/自动续期、保留文件/HTTP/PEM 兼容模式实施。其余字段布局、校验组件和内部任务实现由开发者决定。

## 已批准及实施期间用户追加要求

用户已确认“按方案实施（推荐）”。2026-11-13 追加以下明确要求，纳入同次交付：

- 修复编辑节点时协议选择器总显示 VLESS REALITY，回填实际协议及参数。
- 全部协议支持一键生成正确配置，保留可修改；REALITY 默认 SNI/目标使用 addons.mozilla.org（普通 TLS 仍须自己的证书域名）。编辑原协议的参数修改保留密钥，换协议/ENC 方式才显式重新生成。
- 用户连通性改为服务器自动自测，不需要用户手动触发。实现选择：复用节点每五秒的任务轮询，由面板每节点约五分钟安排一次真实自测，最多四个在途任务/机器；不依赖浏览器访问。结果共享到可用该节点的账号，仅公开状态，不公开用于自测的账号凭据。无人满足权限时明确说明，不绕过额度/套餐。
- 节点管理先显示归属服务器卡片，进入卡片后管理该机器节点；新建默认对应归属。卡片支持拖拽及按钮排序，布局存入当前管理员账号的数据库记录。
- 尝试显示服务器国家：仅使用已确认物理公网 IP，向固定 Country.is HTTPS 指定 IP 接口查询，并验证响应 IP 匹配；不使用访问者出口查询，不能用 WARP IP，失败显示未知。成功缓存一天、失败约一小时再试；仅发送物理公网 IP，不发送任何账号或密钥。地域数据库仅作参考。
