# 账户、套餐权限、订阅持久显示与连通性检测

## 目标与现状

用户明确要求管理员也能使用节点、刷新后仍显示原订阅链接、用户管理具有截图中全部操作、选定落地可测试、用户侧有节点连通性页、每个节点可多选套餐、每月按开通购买日重置流量，以及节点列表直接启用/停用。

保留现有 Go/Vue/PostgreSQL/Compose 和 Luma/Caddy 双仓，节点为原生二进制。现有订阅仅保存摘要，节点用户接口排除 admin，节点无套餐关联，used_bytes 为累计配额计数；订单、邀请、自动月度周期和主动代理检测尚不存在。原生运行时零用户不启动内核；新增第一个用户的热更新路径还需回归，不能依赖手动重启。

## 实施方式与取舍

订阅可使用浏览器本地缓存或服务端加密保存。采用服务端加密保存：跨浏览器、刷新和重新登录都可读取；数据库继续用摘要匹配外部订阅，用现有 LUMA_MASTER_KEY 加密可显示副本。浏览器不保存永久凭据到 localStorage。

连通性可只从面板连接端口，或由对应节点机执行真实协议测试。采用节点机真实协议测试：能检查认证、TLS/REALITY、UDP 协议和代理到目标的往返，且来源与实际落地出口一致。单纯 TCP 握手不能说明代理可用，不能把“端口开了”显示成“节点正常”。界面注明检测来源、时间、耗时与失败阶段，不声称代表用户当地公网质量。

业务变更放在面板；原生节点新增受限检测任务及空用户转为首个用户的启动修复。不引入支付网关，不伪造支付成功；订单是后台手工分配套餐所产生的真实记录。用户已选择公开邀请注册链接：登录用户获取稳定邀请链接，新用户凭有效邀请注册普通账号，记录邀请人；新注册默认零额度，由后台订单分配套餐，不接在线支付，不默认赠送流量。

## 管理员与节点/套餐权限

管理员和普通用户都按启用、剩余额度、到期时间判断下发；角色只控制管理权限，不单独豁免额度。节点编辑增加套餐多选。未选择套餐表示所有符合条件账号可用，维持历史节点范围；选择后仅相同 plan_id 的账号可用，管理员也遵守该范围。没有套餐的账号只能使用不限制套餐的节点。

同一权限条件用于订阅、原生用户接口、MTProxy/连接器、用户节点列表和检测；拒绝越权测试或返回不可见节点资料。保存节点和套餐关联与现有落地路由使用同一事务，非法套餐使整个保存回滚。旧 API 未提供 plan_ids 时保留关联，显式空数组清空限制。

节点列表行内启用/停用，不必打开编辑。独立 PATCH active 接口只修改状态，不用整份旧配置覆盖新配置；失败时恢复开关并显示错误。停用后退出机器发现/用户订阅和连接器期望集，原生同步停止该节点；恢复后重新发现。

## 稳定订阅链接

登录用户 GET 获取自己的链接，首次无链接时创建一次；重复 GET、刷新或并发访问返回同一链接。只在明确点击“重置订阅链接”或管理员“重置 UUID 及订阅 URL”时轮换并撤销旧链接。自己和管理员可读取，其他普通用户不可读取。

历史只有 hash 的链接不可反推。升级不自动使旧链接失效：允许用户粘贴现有链接验证摘要后补存加密副本；若原链接已遗失，明确提示只需手动重置一次。此后刷新始终保留。缺失/错误主密钥时明确报错，不静默生成新链接。

## 用户管理操作

按截图提供操作菜单：编辑、分配订单、复制订阅 URL、重置 UUID 及订阅 URL、TA 的订单、TA 的邀请、TA 的流量记录、重置流量、删除。

编辑保留密码/额度/有效期/启用；显示套餐、开通日、下次重置日，邀请范围确定后增加邀请人字段。分配订单选择套餐，保存套餐价格/额度/时长快照及操作者，客户端请求 ID 保证重复点击不重复开通。新开通或换套餐开启新额度周期；同套餐未到期续费延长到期时间，保留本周期用量和原开通日。所有更新与订单记录原子提交。

订单列表显示真实后台分配记录和状态，不提供不存在的支付信息。流量记录复用现有按账号过滤的真实统计，管理员可从菜单直接打开选定用户。

重置流量仅清零本周期额度计数，记录操作者、时间和原计数，不删除 usage_reports、usage_entries 或 billing_ledger。手动重置不改变每月开通日；重置之前的迟到上报仍保留历史，不重新扣本周期。

删除为逻辑删除：停用、撤销登录会话和订阅、移除节点下发，保留历史账本和外键。必须确认，禁止删除自己和最后一个有效管理员；列表隐藏已删除账号。重置 UUID 会使旧客户端凭据失效，界面须明确告知。

## 每月按开通日重置

采用面板配置 TZ 的本地日历，在开通日每月 00:00 重置；界面显示该时区。29/30/31 日遇到短月份取月末，下一月恢复原锚定日，不漂移。原开通锚点独立保存，不通过“上次重置加一个月”推算。

已有用户迁移不立即清空现有用量；以已有开通/创建日作为锚点，显示下一次重置。后台定期检查并在授权/订阅/节点拉取前补偿检查，面板停机后跨越多月可恢复到当前周期。行锁保证重置、手工重置、订单分配和上报并发不丢账。

额度计数表示当前周期，历史统计/账本表示完整历史。迟到旧周期上报写入完整原始记录和账本，不消耗新周期额度；跨界上报继续沿用现有 period_end 归属规则，界面/文档说明其精度由上报窗口决定，不假定有逐字节时间戳。重复报告仍只计费一次。

## 落地与节点检测

节点编辑在选定服务器和落地后显示“测试连通性”，测试无需先保存节点。任务只允许引用已保存落地与有权管理的服务器，由对应节点机拉取短期任务。按所选内核生成结构化 outbound，经真实协议访问受限测试目标；UI 显示排队/执行/成功/失败/超时和毫秒耗时。分流各落地也可分别测试，直连有明确测试入口。

用户左侧增加“节点连通性”，只列出其套餐允许的节点，显示节点启用、近期上报、最近真实测试结果和检查时间，并提供单节点/受限批量检测。近期心跳和真实代理探测分开显示；从未检查、任务等待、旧节点不支持检测、账户不满足使用条件，都不伪装成“正常”或“故障”。MTProxy 独立 worker 不支持通用网页代理时显示实际连接器状态与检测边界，不虚构网页成功。

用户节点检测必须以该用户的实际 UUID/协议凭据，经该节点配置的入站协议和对外地址，完成访问测试目标的真实请求；不可仅复用落地 outbound 测试。入站未监听、错误认证、TLS/REALITY 握手失败应失败，成功意味着本次从归属机器经节点入站、配置路由/落地到目标的请求完成。检测结果绑定用户和节点，账户被停用、到期或额度用尽应显示账户不可用，不据此标记全节点故障；套餐限制在任务创建和领取时再次核对。探测流量可能产生少量实际计费，不旁路认证或额度规则。来源为节点机自身，不代表其他网络的外部可达性。

检测任务具备身份与机器归属检查、限速、并发上限、固定目标/严格目标白名单、超时、任务过期和结果归属校验。凭据加密存储、仅下发给指定机器，结果不返回原始配置/私钥/远端响应正文。节点端不可执行任意命令，不停止现有代理服务；临时内核使用独立资源，完成后释放。

## 验收与发布

必须覆盖真实 PostgreSQL 权限、订阅并发稳定读取/历史链接补存/重置撤销、套餐过滤全路径、月末/闰年/跨月离线恢复/迟到报告/重复报告/手动重置并发、订单重试幂等、软删除账本保留与最后管理员保护。

检测要有真实本机代理成功、错误认证、断开、超时、越权/跨机器、过期任务及资源清理回归；原生新增用户从 0 到 1 自动开始监听也须先失败再通过。前端检查菜单、刷新不丢订阅、用户隔离、套餐多选、列表开关错误恢复、检测结果与移动布局。

两个公开仓库分别发布功能分支和 PR，跟进对应 SHA 的 Linux CI。先发布新版双架构原生包并实际下载校验，再合并面板，给出面板更新及既有节点升级说明；不代替用户登录生产服务器。迁移与回滚须备份数据库及同一主密钥。

## 用户追加需求（同批实施）

- 节点列表增加删除按钮和确认。逻辑删除、停用、撤销节点认证并解除机器归属；节点历史流量与账本保留，不让旧编辑/启用请求复活已删除节点。
- 节点列表和管理员节点动态提供“故障查询”。指定节点机受限读取最近十分钟、最多120行日志（固定命令、三秒、64KiB），仅返回固定分类脱敏摘要，不返回原始日志；结合该节点真实运行状态、有效用户数量及 TCP/UDP 监听分析。机器范围日志不能冒充该节点的确定证据。离线/认证失效无法获取远程日志时明确显示不可用。
- 选择归属服务器时，自动填入已确认物理网卡的公网 IPv4，缺少则 IPv6；手填域名保留，提供手动选择检测地址。节点机排除 WARP/WireGuard/TUN 等虚拟隧道接口及私有/CGNAT/保留地址，不使用出口查 IP 网站，不修改路由；NAT或无法确认时留空并提示手填。

## 延迟显示修订（用户明确要求）

落地测试先验证代理连通，成功后测节点机到该落地地址的 ICMP Ping 平均往返延迟；不显示 HTTP 请求耗时。ICMP 无响应/无权限/解析失败与代理连通结果分开，不能把可用代理判为故障。直连和没有指定落地的用户入站测试不虚构 Ping。最多三次、最多三秒，随机标识/序号/载荷及源地址匹配，使用原生ICMP套接字，不执行ping子进程。Linux CI以实际权限验证本机ICMP往返。
