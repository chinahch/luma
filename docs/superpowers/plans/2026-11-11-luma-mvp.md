# Luma Portable Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 可自行部署、开源且便于迁移的节点管理与用户流量面板预览版。

**Architecture:** Go/Gin API + PostgreSQL 真值 + Redis 可重建缓存；Vue3/TypeScript/Naive UI；Nginx 同源前端代理。节点 legacy 接口与可靠批次接口明确区分，不向旧协议承诺准确一次计费。

**Tech Stack:** Go 1.26、Gin、pgx、bcrypt、Redis、Vue3、TypeScript、Naive UI、Vite、Docker Compose。

**Spec:** ../specs/2026-11-12-open-source-design.md（已批准，面板为 Luma）

## Global Constraints
- Public 仓库 chinahch/luma；不提交凭据、数据库、运行日志或真实用户数据。
- UTC 保存时间；查询按明确时区返回，普通用户只能访问自己的记录。
- 初版为 preview，旧协议流量只能尽力统计；生产上线另行验收。
- 单机 Compose，数据库和 Redis 不向公网映射端口；数据通过数据库备份迁移。

## Review Focus
- 已提交后响应丢失：相同可靠批次重试不重复计费；同 ID 不同内容返回冲突。
- 节点越权与 Machine 混报：token 只能访问授权归属，不能伪造 node_id。
- 日期/时区/金额：跨日区间与倍率快照确定；负数、溢出、重复用户拒绝。
- 未登录/普通用户不得读取他人流量、创建账号、取得节点 token。
- Redis 不可用时不丢持久用量，迁移恢复后用户凭据与账本一致。

## Task 1: 业务流量计算与校验
**Files:** internal/traffic/report.go、report_test.go。
**Interfaces:** Report{ReportID,PeriodStart,PeriodEnd,Entries[]Entry{UserID,Up,Down}}；Validate(now time.Time) error；Bill(up,down int64,milli int64)(int64,error)。
- [ ] 写测试：负数/重复用户/未来时间/超过 24h 窗口拒绝；1500 倍率千分数对 100+200 字节计费 450；小数向上取整；溢出拒绝。
- [ ] 运行观察失败；实现整数校验与整数计费；运行整个 traffic 包通过。

## Task 2: PostgreSQL 模型与事务幂等
**Files:** internal/store/store.go、schema.sql、reports.go、reports_test.go。
**Interfaces:** Open(ctx,dsn)(*Store,error)、Migrate(ctx) error、Ingest(ctx,nodeID,report)(bool,error)；ErrConflict、ErrForbidden、ErrInvalid。
- [ ] 使用真实测试 PostgreSQL 写事务测试，重复报告不新增账本/用量；改内容同 ID 冲突；无授权用户整批回滚；累计额度溢出整批回滚。
- [ ] 建 users、sessions、plans、machines、nodes、usage_reports、usage_entries、billing_ledger、login_attempts；唯一键(node_id,report_id)、FK、非负约束、时间索引。
- [ ] 在同一事务中锁节点、插批次、用户额度累加、账本写入。报告保存倍率快照，重复批次在倍率改变后仍返回旧结果。
- [ ] 写查询实现：时区范围、节点/用户过滤、小时/日/月分组；用户归属由认证边界限定。

## Task 3: 会话、管理与旧节点协议
**Files:** internal/httpapi/server.go、auth.go、admin.go、node.go、queries.go、server_test.go；cmd/luma/main.go。
**Interfaces:** New(store,*redis.Client,Config)*gin.Engine；Config{SecureCookies,AllowedOrigin}；GET /api/me、POST /api/login/logout；/api/admin/users/plans/machines/nodes；/api/usage、/api/dashboard；/api/v3/server/report；实际旧 v1/v2 节点接口。
- [ ] 先写 HTTP 测试：未登录401、普通用户403、错误 token401、Machine 越权403、可靠报告重复200+单次扣费、legacy 报告标记质量。
- [ ] 实现 bcrypt 密码、随机 opaque session HttpOnly/SameSite Cookie、数据库 login 限速、同源写请求检查与严格输入体积限制。
- [ ] 管理 CRUD 的新节点/Machine token仅创建时返回；数据库只存 token 哈希。用户 UUID 保留用于协议认证，订阅 token只存哈希。
- [ ] REST 旧节点握手关闭 WS以使用轮询；Node/Machine 配置与用户响应遵循固定客户端形状。
- [ ] 实现登录、权限、基础管理、用量查询、CSV导出、VLESS订阅与额度/有效期过滤。未实现协议在界面与文档标注。
