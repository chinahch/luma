# 服务器自动接入

1. 服务器管理 → 添加服务器 → 复制安装命令。
2. 在目标 Linux amd64/arm64 主机以 root 执行。节点不需要 Docker、Go 或 Python；命令自动安装原生服务和配置认证，不要求复制令牌。安装前已有可信服务时会自动识别并重新接入。
3. 返回面板，等待心跳；零节点也能在线。CPU、内存和磁盘只展示实际采样，缺少数据时显示暂无数据。
4. 节点管理 → 新建节点 → 选择归属服务器和协议。在“落地与分流”选择已添加的默认落地，按需添加域名后缀/IP网段规则，然后保存。节点及路由在同一事务中保存；不兼容或停用的落地会拒绝本次保存。
5. 原生节点通常在下一次10秒同步时发现/更新。协议或内核变化会重建对应节点服务，临时启动失败可在修正配置后重试。服务器在线只代表控制面连通，仍需检查实际代理连接。

安装命令带15分钟接入权限，请勿公开转发。到期或尚未完成的命令可重新生成；新命令不会直接影响运行中的服务，执行并成功登记后才改变认证。客户端先私密持久保存随机凭据，再登记；响应丢失时重复提交同一凭据不会产生不同身份。过期未完成的安装可用同一服务器的新命令续接，保留原候选凭据。数据库只保存摘要，日常界面不显示永久凭据。

面板地址必须从服务器可达，不能使用电脑 SSH 转发的 localhost。现有 HTTP 部署仍可使用，生产建议 HTTPS。安装器拒绝不明 Caddy Web Server/服务、面板或机器身份不匹配，以及共享或内嵌凭据等不能安全更新的定制配置。CF/MTProxy 的独立连接器仍单独安装；已有同身份连接器时需协调迁移，避免只更新原生服务而使连接器失去认证。

服务器编辑支持修改名称。删除仅允许没有关联节点的服务器，不删除节点或账本，不远程卸载进程。需先迁移节点归属并在旧主机停止对应服务。迁移时同时保存数据库、相同主密钥、私有配置，以及连接器队列。数据库当前版本4；从v3自动升级增加接入记录，回滚使用兼容代码或更新前备份恢复到新实例。
