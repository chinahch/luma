# 账户、套餐、订阅和故障检查

管理员与普通用户均可使用节点，须启用、未到期、有剩余本周期额度，并符合节点套餐范围。初始管理员默认没有流量，可在用户管理修改额度或分配套餐。

## 用户管理与套餐

用户操作菜单提供编辑、分配订单、复制原订阅 URL、重置 UUID 及 URL、订单、邀请、流量记录、本周期流量重置和删除。后台分配订单记录操作者及套餐价格/额度/时长快照；同次提交重试不重复开通。未到期同套餐续费延长到期并保留周期用量/开通日，新开通或换套餐开始新周期。当前无在线支付，不把手动分配标为付款。

节点编辑可多选套餐；留空表示不限制套餐。无套餐账号只可使用未限制节点。节点列表可直接启用、停用、删除；删除停用并撤销认证、解除服务器归属，保留历史账本。用户删除撤销登录/订阅和下发，同样保留历史；不能删除自己或最后一个有效管理员。

## 每月额度

按面板 `TZ` 的开通日每月 00:00 重置。29–31 日遇短月份取月末，下月恢复原锚定日。后台和请求时补偿检查可处理停机跨月。迁移不会立即清空已有用量；显示下一次重置时间。

重置仅清本周期计数并记审计，不删除原始上报/流量/账本。旧周期迟到报告仍写历史，但不扣新周期。跨界采集窗口沿用 period_end 归属，精度由上报窗口决定。手工重置不改变月度开通日，重置前的迟到报告不重新消耗当前额度。

## 订阅与邀请

我的订阅从服务端读取加密保存的稳定链接，刷新、重新登录不轮换。仅明确重置时旧链接失效。须备份相同 LUMA_MASTER_KEY；错密钥时报错，不静默生成新链接。历史只存摘要的链接无法反推；粘贴原链接可补存且不撤销它，已遗失则明确重置一次。

邀请好友页提供稳定邀请注册链接及真实邀请记录。有效邀请可注册普通账号；注册默认零额度，由管理员分配套餐后使用。公开注册限速，不自动赠送套餐，也不接在线付款/邮件验证服务。

## 连通性和 Ping

节点编辑选定服务器及默认/规则落地后可测试，不必先保存节点。原生节点创建隔离客户端，验证对应代理协议、认证、TLS/REALITY 和真实 HTTPS 往返。落地验证成功后，再从节点机向该落地地址发送最多三个 ICMP Echo，显示平均 Ping RTT（ms）。不显示 HTTP 请求耗时。ICMP 被禁止、无响应或权限不足与代理失败分开显示。直连及无指定落地的用户入站测试不编造 Ping 延迟。

用户侧节点连通性只显示有权限的节点，使用该用户实际凭据经过节点入站和已配置路由/落地进行测试。检测来源是节点机，不代表用户当地网络或所有外部网络可达性；可能产生少量实际计费。MTProxy 仅显示真实连接器状态，不伪造通用网页代理结果。

## 故障查询和地址填入

管理员节点列表/运行概览提供故障查询，查看该节点运行句柄、有效用户数量、配置端口与 TCP/UDP 监听。H3 按 UDP 处理。诊断成功只代表取回资料，不代表代理连通；端口可能属于其他进程。日志仅为固定范围、最近十分钟、最多120行的脱敏分类摘要，明确属于整台机器，不冒充该节点确定错误；原始日志和密钥不会返回面板。

节点离线或认证失败时面板不能绕过网络读取日志，会显示无法获取；近期心跳存在但缺少新检测能力时提示升级原生服务。

选择归属服务器可自动填入最近两分钟报告的物理接口公网 IPv4，缺少则 IPv6。排除 WARP/WireGuard/TUN、私有/CGNAT/保留地址，不使用查出口 IP 网站，不改服务器路由。旧地址仅供明确手动选择；手填域名/IP 保留。NAT-only 或无法确认物理接口时留空，需手动填入可验证公网地址。

## 更新

先备份数据库、私有 .env/同一主密钥及证书。在面板源码目录运行：

```sh
sh scripts/backup.sh && git pull --ff-only && docker compose up -d --build --wait
```

数据库自动迁移到6。刷新浏览器加载新前端。已有节点机需更新到 v0.1.3-preview（版本含 luma-v2）才能检测、诊断及报告物理公网地址：在服务器管理的原服务器记录重新生成安装命令，到原节点机执行，保留原配置并通过已验证接入流程更新原生包。不要删除服务器记录或配置目录；独立 CF/MTProxy worker 保留原迁移限制。节点机不需要 Docker。

回滚不直接降级数据库；使用更新前备份及匹配程序恢复到独立实例。真实目标主机重启、公网、防火墙、NAT/hairpin 和容量仍需在目标环境验证。
