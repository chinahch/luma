# 节点证书、协议生成与服务器卡片

节点机使用原生 caddy 二进制，不需要 Docker。本次原生版本为 v0.1.4-preview（版本含 luma-v3）；面板数据库自动升级到版本 7。

## 添加节点

进入「节点管理」，点击归属服务器卡片，再点「新建节点」。服务器与已确认的物理公网地址自动填入；不能确认地址时请手工填写，系统不使用 WARP 出口 IP。

选择协议后点「一键生成配置」。全部协议预设及六种 ENC 组合均沿用对应原生内核的配置生成器。生成时可自动避开面板中该服务器已分配的监听/指标端口，但不能代替节点机上其他软件的端口检查；实际冲突会在故障查询中反映。生成后的端口、域名、路径、落地和路由仍可修改。

REALITY 默认 SNI 和握手目标为 addons.mozilla.org / addons.mozilla.org:443。这是默认值，可修改。普通 TLS 证书必须使用你自己控制、且能完成验证的域名；不能为 addons.mozilla.org 申请证书。CF Tunnel 需自己的隧道令牌，MTProxy 需选择归属账号，系统不伪造这些外部条件。

编辑节点会读取原协议、端口、SNI、路径等参数；普通保存或「应用参数（保留密钥）」不会重新生成协议密钥。切换协议或 ENC 认证方式后需显式重新生成。重新生成配置与密钥有确认提示，旧客户端配置可能失效。自定义协议无法可靠识别时显示自定义状态，不会假装是 VLESS REALITY。

## 自动证书

需要普通 TLS 的组合显示证书表单。新建默认 DNS-01（ACME），填写证书域名、具体 SNI、通知邮箱、DNS 提供商和凭据。每行 KEY=VALUE，按第一个等号分隔，值中后续等号保留。Cloudflare 例子：

```text
CF_API_TOKEN=在这里填写你新建的令牌
```

表单提供当前原生版本内置的 DNS 提供商及对应变量说明。仅选择域名实际使用的 DNS 提供商；更换厂商需填写完整新凭据。凭据作为数据传递，不能填写 export 命令或多行 shell 脚本。泛域名证书需覆盖具体 SNI，客户端不能使用泛域名作为 SNI。

DNS 凭据及 PEM 私钥加密保存在服务端。再次编辑只显示“已保存”，留空保留，输入完整新内容可替换；模式/厂商变化不会暗中沿用旧密钥。节点列表、订阅、检测结果不包含这些凭据。

GoDaddy 可填写 `GODADDY_API_TOKEN=KEY:SECRET`，或同时填写 `GODADDY_API_KEY` 与 `GODADDY_API_SECRET`；两种方式任选其一。

保存后由归属服务器通过既有受认证同步接口自动获取配置，并在节点机申请和续期证书。保存成功并不表示已签发。首次申请失败不启动无证书的普通 TLS 监听；相同配置会在后续同步重试，可用节点列表「故障查询」查看固定的证书状态。DNS 权限、DNS 传播、网络及 CA 限流仍可能导致申请失败。

HTTP-01 要求证书域名解析到节点机、公网 TCP 80 可达且未被其他服务占用，不支持泛域名。也可选择节点文件路径或粘贴 PEM 证书与私钥。已有文件模式不会自动改成 DNS。

## 自动连通性与卡片布局

节点机现有轮询在后台自动安排自测，每节点约五分钟一轮；不依赖用户打开页面，也不需要点击测试。面板为自测选择符合套餐、有效期和剩余额度要求的实际账号，仍走真实入站、路由和落地，因此可能产生少量计费用量。没有可用账号时说明原因，不绕过账户限制。

用户端「节点连通性」每十五秒读取最新服务器自测结果。服务器心跳与代理连通性分开显示，十分钟以上的结果显示已过期。MTProxy 显示实际连接器状态，不把普通网页代理测试当成 Telegram 协议验证。管理员编辑落地时的单次连通性测试及后续 ICMP Ping 保留；显示节点机到落地的 Ping RTT，不显示 HTTP 请求耗时。

服务器卡片可拖拽或使用前移/后移按钮排序；布局保存到管理员账号的数据库记录，换浏览器或迁移数据库仍可恢复。

国家识别只查询已确认物理网卡的公网 IP。使用 [Country.is 的指定 IP 查询接口](https://country.is/)，向其发送该公网 IP，不发送面板身份、用户信息或 DNS 凭据；不会调用“查询访问者自身 IP”的接口。成功缓存一天，失败约一小时后重试；地理数据库仅作参考，无法识别时显示国家未知。查询不影响服务器心跳，也不会把 WARP 出口所在地作为真实服务器国家。

## 更新

不同用户的节点凭据使用各自的账号 UUID；同一账号在多个节点使用同一个 UUID。单独重置订阅 URL 只撤销链接，保留节点 UUID；需同时撤销节点凭据时，管理员使用“重置 UUID 及订阅 URL”。不能只通过比较某个账号新旧链接判断是否是不同用户身份。

备份并保留原 .env 与 LUMA_MASTER_KEY，在面板服务器执行：

```sh
cd /opt/luma && sh scripts/backup.sh && git pull --ff-only && docker compose up -d --build --wait
```

在服务器管理的原服务器记录重新生成安装命令，到对应原节点机执行，更新至 v0.1.4-preview。不要删除原机器记录或配置目录；独立连接器仍遵守现有迁移限制。完成后刷新浏览器。升级不会替你控制的域名和凭据自动完成公共 CA 验证，首次公网签发需在实际服务器检查。
